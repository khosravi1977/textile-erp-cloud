# Textile ERP Telegram Relay

واسط حداقلی و امن برای عبور درخواست‌های گزارش تلگرام از شبکهٔ خارج ایران.

- فقط چهار عملیات موردنیاز بات را می‌پذیرد.
- همهٔ درخواست‌ها به کلید محرمانهٔ سرویس نیاز دارند.
- توکن بات در نشانی ورودی، کد، لاگ یا مخزن ذخیره نمی‌شود.
- اندازهٔ بدنه، روش درخواست و پارامترهای قابل عبور محدود هستند.
- مسیر سلامت نیز بدون کلید معتبر اطلاعاتی نمایش نمی‌دهد.

مقادیر محیطی فقط در میزبانی تولید تنظیم می‌شوند:

```text
TELEGRAM_RELAY_TOKEN
```

کنترل محلی:

```text
npm ci
npm test
```
