# مرکز فرمان سه‌گانه مدیر نساجی

این برنامه یک داشبورد نصب‌پذیر و فقط‌خواندنی برای مدیر است. همان نسخه در مرورگر موبایل اندروید، آیفون، رایانه، لپ‌تاپ و تلویزیون هوشمند اجرا می‌شود.

## سه بخش برنامه

۱. عملیات: تولید روز و ماه، تعداد طاقه، موجودی پارچه، وضعیت انبار، هشدارها و مقایسه ماشین‌ها.

۲. مالی: فروش، خرید، هزینه، حاشیه سود، موجودی بانک و صندوق، مطالبات، بدهی‌ها و هشدارهای مالی.

۳. راندمان سالن: در نسخه پایه، وضعیت چله، تولید، مواد باقی‌مانده و ضایعات هر ماشین را از بخش عملیاتی نمایش می‌دهد. با اتصال سامانه تخصصی سالن، راندمان واقعی ماشین و بافنده، توقف‌ها، رتبه‌بندی بافنده‌ها و زمان آخرین داده تأییدشده به‌طور خودکار جایگزین داده پایه می‌شود. اگر منبع تخصصی داده آزمایشی اعلام کند، هشدار واضح نمایش داده می‌شود.

## امنیت و دسترسی

- برنامه فقط برای نقش مالک یا مدیر اجرایی باز می‌شود.
- کاربر باید هم‌زمان اجازه مشاهده بخش مالی و عملیاتی را داشته باشد.
- اطلاعات برنامه فقط خواندنی است و از این داشبورد امکان تغییر حساب یا تولید وجود ندارد.
- رمز و کلید اتصال سامانه سالن هرگز به مرورگر ارسال نمی‌شود.
- اطلاعات مالی و تولید روی دستگاه ذخیره نمی‌شود؛ در حالت قطع اینترنت فقط پیام آفلاین نمایش داده می‌شود.
- هر بار دریافت داده، با نشست کوتاه‌مدت همان مدیر انجام می‌شود.

## نمایش روی تلویزیون

با فعال‌کردن «حالت تلویزیون»، نوشته‌ها و شاخص‌ها بزرگ‌تر می‌شوند و سه تب هر ۲۵ ثانیه به‌صورت خودکار جابه‌جا می‌شوند. اطلاعات زنده نیز هر ۶۰ ثانیه به‌روزرسانی می‌شود.

## قرارداد اتصال سامانه تخصصی سالن

سامانه تخصصی باید یک نشانی فقط‌خواندنی و امن ارائه کند. نمونه ساختار پاسخ:

{

  "module": "textie-weaving-efficiency",
  "basis": "latest-confirmed-complete-shift",
  "generatedAt": "2026-08-01T08:30:00Z",
  "sample": false,
  "hall": {
    "efficiency": 94.2,
    "activeMachineCount": 8,
    "totalStops": 17
  },
  "machines": [
    {
      "number": 1,
      "weaverName": "نام بافنده",
      "efficiency": 95.4,
      "meters": 1280,
      "stops": 2,
      "status": "good"

قرارداد قدیمی با فیلدهای هم‌سطح نیز پذیرفته می‌شود، اما درگاه قبل از تحویل به مرورگر همه پاسخ‌ها را به یک ساختار محدود و استاندارد تبدیل می‌کند. مقدار متراژ تأییدنشده خالی می‌ماند و به‌اشتباه صفر نمایش داده نمی‌شود.

نشانی و کلید اتصال فقط روی سرور قرار می‌گیرند:

```text
PORTAL_WEAVING_MONITOR_SUMMARY_URL
PORTAL_WEAVING_MONITOR_TOKEN
```

## انتشار و بازگشت

این قابلیت داخل تصویر غیرقابل‌تغییر درگاه نساجی ساخته می‌شود و داده یا حجم جدیدی ایجاد نمی‌کند. انتشار آن با همان مسیر تأیید، ادغام و استقرار پروژه انجام می‌شود. برای بازگشت کافی است تصویر قبلی درگاه دوباره فعال شود؛ پایگاه داده و اطلاعات عملیاتی و مالی دست‌نخورده باقی می‌مانند.
